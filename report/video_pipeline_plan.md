# 影片這條線：接下來的計劃

寫於 2026-11-19。這份只講計劃，還沒動任何程式。

## 一、整體想做成什麼樣子

```
urls.csv 讀進來
   │
   ▼
【分析檔】每個網址一列，先判斷是什麼類型
   │
   ├─ 網頁 ─┬─ 架構 A → 爬蟲 A          （同事負責）
   │        └─ 架構 B → 爬蟲 B          （同事負責）
   │
   └─ 影片（你負責）
        ├─ 有字幕 → 取字幕 → 分析重點 → 在重點時間點截圖
        └─ 沒字幕 → FunASR 兩個模型 + 畫面字幕 OCR 校對
                     → 不確定的地方 → 網頁讓人工確認
```

## 三、接下來的步驟

### 第 0 步：先跟同事對齊（不寫程式）
要對的只有三件事：
1. **分析檔長什麼樣子。** 我建議一個 csv，每個網址一列，欄位至少有：編號、網址、類型（網頁／影片）、子類型（網頁架構 A／B；影片有字幕／無字幕／非 YouTube）、判斷理由、交給哪個處理程式。
2. **輸出資料夾約定。** 影片的結果放 `output/videos/<編號>/`，網頁放 `output/articles/`，這個現在已經是這樣，確認不要改。
3. **能不能跑在你同事的電腦上。** README 是以 Windows 寫的，但我們的畫面字幕 OCR 用的是 Apple Vision，**只能在 Mac 上跑**。FunASR 兩邊都能跑。要決定：OCR 只在你的 Mac 上跑、結果檔交給同事？還是需要 Windows 版？

### 第 1 步：影片分流器
- 對每個影片網址，用 yt-dlp 只讀資訊（不下載影片），分成四種：**上傳者提供字幕／只有自動字幕／完全沒字幕／不是 YouTube**（例如文化部自己的播放器）。
- 結果寫進分析檔的那一列。
- 需要先在這台 Mac 裝 yt-dlp（用 Homebrew）。
- 驗收：對 csv 第 26、27、30 筆實跑，分類結果和 `site_analysis.md` 一致（26、27 有字幕，30 沒有）。

### 第 2 步：有字幕路線（這是目前最大的缺口）
1. **取字幕**：優先上傳者提供的，語言順序中文優先。清掉 YouTube 字幕常見的重複行。
2. **分析重點**：把字幕切成段，每段列出「這段在講什麼、起訖時間」，再挑出重點。
3. **重點截圖**：在每個重點的時間點截一張畫面，存到 `output/videos/<編號>/frames/`，檔名帶時間，並寫進輸出的 Markdown，旁邊附那一句字幕。
4. 輸出：`video.md` 之外多一份 `重點.md`。
- 測試影片：第 27 筆（23 秒短片）先測流程，再跑第 26 筆（38 分鐘）。
- **截圖需要影片檔，也就是要下載影片。** 每一支下載前我會先問你。

### 第 3 步：沒字幕路線的收尾
這條已經能跑，剩下的是讓它在別支影片也站得住：
- 再找第二支沒字幕的影片實測。已知的候選是嵌在第 13 筆裡的農業部影片（23 分鐘，沒字幕、不在 csv）。要下載，需要你同意。
- 修 `_lookup_record`：現在對 page030 找不到對應紀錄，要用手動繞過。
- 把 FunASR 需要的套件寫進 requirements（現在只寫了 Whisper 的）。
- 片尾 13:13–13:35 的上方宣傳字卡、0:27–0:36 的空窗、OCR 常漏掉「的」這三個已知缺口。
- 專有名詞檔：把「待確認」的 3 筆確認後升級。

### 第 4 步：合成一個入口
- 一個指令：給影片網址 → 分流 → 自動走有字幕或沒字幕路線 → 結果放同一個資料夾格式。
- 跟同事的網頁部分合併到同一份 `index.jsonl`，欄位對齊（看第 0 步對出來的結果）。

### 第 5 步：文件與提交
- 更新 README 與 RESULTS（現在 README 還寫著所有影片都跑 Whisper，已經不符現況）。
- 你確認內容後再 `git commit`（我不會自己提交）。

## 四、順序建議

第 0 步 → 第 1 步 → 第 2 步 → 第 3 步 → 第 4、5 步。
理由：第 0、1 步很小，但決定後面所有東西怎麼接；第 2 步是目前最大的空白；第 3 步是把已做的做得更穩。

## 五、要你決定的事

1. **「重點」由誰判斷？**
   - 我在對話裡讀字幕整理（跟專有名詞、AI 建議同一種做法，免費、品質我可控，但每支影片都要開對話跑一次，不能自動化）。
   - 程式呼叫 AI 服務自動做（可以全自動，但要 API 金鑰與費用，且要考慮影片內容送到外部服務）。
2. **只有自動字幕的影片，算有字幕還是沒字幕？** 自動字幕常有錯字。我建議：算「有字幕」但標註「自動字幕，未校對」，並可選擇再跑一次 FunASR 對照。
3. **OCR 只在 Mac 上跑可以嗎？** 要看你同事的環境。
4. **每支需要截圖的影片，下載前都問你一次？** 我預設是這樣。
