# 桃園市觀音區知識庫爬取工具

這是一套可重複執行的 Python 爬取工具，會處理 `urls.csv` 中實際列出的 32 個原始網址，分辨一般網頁與 YouTube，保存文章文字、標題、來源網站、可合法下載的主要圖片與圖片說明、頁面超連結，並依設定從與觀音區主題相關的連結做有限延伸探索。任務圖片寫 31 個網址，但來源 CSV 實際列出 32 筆；本工具保留 CSV 全部來源。每次執行會重建輸出資料，避免舊資料與新結果混在一起。

## 安裝與執行

需要 Python 3.10 或更新版本。

```powershell
cd guanyin-crawler
py -m venv .venv
.venv\Scripts\Activate.ps1
py -m pip install -r requirements.txt
py crawler.py
```

預設從來源網址擷取資料，並最多探索一層延伸連結；延伸頁面最多 40 頁、每個網域最多 5 頁，同網域請求至少間隔 1.5 秒。可調整參數：

```powershell
py crawler.py --max-depth 2 --max-extra 60 --per-domain 6 --delay 2
py crawler.py --no-extend
py crawler.py --limit 3 --no-extend   # 小規模確認環境
```

`--max-depth` 可設 0 至 3；深度 0 只處理來源 CSV。爬蟲遵守網站回應與錯誤狀態，不會嘗試繞過登入、付費牆、驗證碼或存取限制。失敗或受限來源會保留在狀態報表，附上錯誤原因。

## 輸出

- `data/records.jsonl`：爬蟲原始紀錄，一行一筆，含 `source_type`（`seed` / `extension`）、`depth`、`discovered_from`（延伸頁的發現來源）、標題、來源、正文、圖片及超連結。
- `output/index.jsonl`：後處理後的完整結構化索引，含一致欄位、主題、關鍵字、圖片下載狀態與查核所需的來源資訊。
- `data/crawl_status.csv`：每個來源與延伸網址的成功、部分成功、無法存取或失敗狀態、HTTP 狀態碼及原因。`inaccessible` 會明確標示 401/403、伺服器錯誤、TLS 憑證、DNS、連線或逾時等無法讀取情況；404 會標示為找不到資源。
- `output/crawl_report.csv`：依輸出 ID 對應的精簡爬取報表。

YouTube 透過 `yt-dlp` 讀取可公開取得的影片資訊和字幕，不下載影片本體；沒有字幕時會記下原因。無法取得字幕的影片不會被偽裝成有逐字稿。一般網頁若受網站限制或需要瀏覽器互動，也可能無法取得完整正文；狀態報表會呈現這些情況。本次執行結果另見 `RESULTS.md`。

影片畫格會先嘗試使用公開播放器擷取時間碼畫面；若播放器回傳錯誤或來源限制串流，`output/videos/video_*_frames/README.md` 會保留錯誤原因，縮圖只作為縮圖保存，不冒充代表畫格。

## 欄位與品質處理

主文優先取文章或主內容區塊；擷取前會移除頁首頁尾、導覽、選單、麵包屑、Cookie／同意提示、訂閱、分享、推薦、留言、分頁、彈窗、script/style、表單與常見廣告版位，再用正文抽取器處理清理後的 HTML。標題、正文、條列、表格、作者與日期（若頁面有提供）會保留；圖片保留圖片網址、替代文字及圖說（若頁面有提供），後處理階段會嘗試下載合格圖片並記錄雜湊。連結會解析相對網址並去除片段重複項。這些是自動化清理結果，若頁面版型特殊仍建議人工抽查。

## 來源清單注意事項

本資料夾中的 `urls.csv` 保留使用者提供的 32 筆網址。第 10 筆甘泉寺維基網址缺少結尾 `)`，爬蟲會照原值嘗試並在狀態報表標記結果。清單末尾另有該條目的完整網址，兩筆來源都予保留；只有完全相同的網址才會去重。

## 報告與查核

- `report/report.md`：任務對應、執行統計、清理策略與限制。
- `data/fact_checks.csv`：三筆地方知識的來源查核摘要。
